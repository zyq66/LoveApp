# LoveLetter V2 产品设计

## 定位

LoveLetter 是一个只给两个人使用的“私人双人胶卷”，不是情侣工具箱，也不替代微信聊天。

核心循环：

```text
留下瞬间 → 对方产生回应 → 以后重新遇见
```

## 信息架构

### 今天

- 显示在一起天数，但不作为主任务。
- 双方各放一张照片，组成“今天的我们”。
- 展示对方最近上传的照片并提供一个轻量回应。
- 用“从前的今天”或随机回忆提供再次打开的理由。

### 胶卷

- 没有 `rollId` 的历史照片按月份自动成卷。
- 普通胶卷用于旅行、周末、生日等共同事件。
- 秘密胶卷在约定日期前隐藏照片，到时双方一起揭晓。
- 每卷显示封面、照片数和当前状态。

### 我们

- 两人的头像与昵称。
- 在一起日期和照片统计。
- 新照片即时提醒开关。
- vivo / 小米后台设置指引。
- 重置本机身份，不提供账号退出或情侣解绑。

## 明确移除

- 手机号、密码、注册、登录和配对码
- 聊天与 AI 情书
- 关怀日历
- 伴侣档案
- 每日任务与独立 AI 入口

对应的 CloudBase 历史集合不会自动删除，便于回滚和人工导出。

## 成功标准

两周实际使用中：

1. 双方都能在没人提醒的情况下主动上传。
2. 收到照片提醒后愿意打开并回应。
3. 会主动翻看以前的胶卷。

如果仍需要一方反复提醒另一方打开 App，应继续减少上传步骤和首页信息，而不是增加新模块。
